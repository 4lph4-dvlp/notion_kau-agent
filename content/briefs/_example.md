# 주제

노션 데이터베이스를 처음 쓰는 사람이 가장 많이 하는 실수 5가지

## 타깃

노션을 쓰기 시작한 대학생. 페이지는 만들어봤지만 데이터베이스는 어려워하는 단계.

## 핵심 메시지

데이터베이스는 "표"가 아니라 "하나의 데이터를 여러 방식으로 보는 도구"다.

## 담을 내용

1. 페이지마다 새 데이터베이스를 만든다 → 하나로 모으고 뷰를 나눠라
2. 속성을 텍스트로만 만든다 → 셀렉트/날짜로 만들어야 필터가 된다
3. 뷰를 안 쓴다 → 같은 DB에 필터만 다른 뷰 3개
4. 관계형(Relation)을 안 쓴다 → 과제 DB ↔ 수업 DB 연결
5. 템플릿 버튼을 안 쓴다 → 반복 입력 자동화

## 톤

- 단정적이고 짧게. "~해보세요"보다 "~하세요".
- 전문 용어는 첫 등장 시 한 줄로 풀어 쓴다.

## 행동 유도 (마지막 카드)

저장해두고 노션 켤 때 보기 + 팔로우
